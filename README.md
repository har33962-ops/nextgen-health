Next Gen Health Smart Care - Demo Project
=========================================

Quick start:

1. Server:
   cd server
   npm install
   npm run seed
   npm start
   (server runs on http://localhost:4000)

2. Client (in new terminal):
   cd client
   npm install
   npm start
   (client runs on http://localhost:3000)

Note: In production set REACT_APP_API_URL to your deployed server URL before building the client.
